# CodeAlpha Hangman Game

## Description

This project is a simple text-based Hangman game developed in Python. The player attempts to guess a randomly selected word by entering one letter at a time. The game allows a maximum of six incorrect guesses before the player loses. It demonstrates the use of Python fundamentals such as loops, conditional statements, lists, strings, functions, and the `random` module.

## Features

* Randomly selects a word from a predefined list.
* Allows one-letter guesses.
* Maximum of six incorrect attempts.
* Prevents repeated guesses.
* Displays the current progress after each guess.
* Announces whether the player wins or loses.

## Technologies Used

* Python 3

## Concepts Used

* Random Module
* While Loop
* If-Else Statements
* Strings
* Lists
* Functions
* User Input

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project in VS Code or any Python IDE.
4. Run the program:

   ```
   python hangman.py
   ```
